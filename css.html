CSS Básico com Libras

CSS é a linguagem usada para deixar as páginas da internet bonitas e organizadas. Ela controla cores, fontes, tamanhos, espaçamentos e muito mais.

Propriedades CSS importantes

color
Define a cor do texto
background-color
Define a cor de fundo
font-size
Define o tamanho da fonte
margin
Espaçamento externo
padding
Espaçamento interno

Dúvidas comuns

Posso usar várias propriedades CSS juntas?
Sim! Você pode usar muitas propriedades para controlar o visual da página.
O que é a diferença entre margin e padding?
Margin é o espaço fora do elemento, padding é o espaço dentro do elemento.
