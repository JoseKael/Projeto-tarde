SINAL HTML EM LIBRAS

HTML é a linguagem que usamos para criar páginas na internet. Ela serve para estruturar o conteúdo, como textos, imagens, links e vídeos.

Principais tags HTML

<h1>
Título principal da página
<p>
Parágrafo de texto
<a>
Link para outra página ou site
<img>
Imagem na página

Dúvidas comuns

O que significa <html> e <body>?
<html> é a raiz do documento, e <body> é o conteúdo visível da página.
Posso usar qualquer texto dentro das tags?
Sim! Mas é importante usar as tags corretas para cada tipo de conteúdo.
